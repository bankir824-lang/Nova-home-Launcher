# NovaTV Launcher 0.3

Лаунчер для Android TV / Google TV 11–14, включая TCL C835. Идентификатор `ru.novatv.launcher` сохранён, versionCode повышен до 3.

## Управление пультом

- Короткое OK (DPAD_CENTER, ENTER, NUMPAD_ENTER) запускает приложение один раз при отпускании.
- Удержание OK открывает меню: избранное, перемещение, настройки приложения, информация, удаление. Отпускание после удержания не запускает приложение.
- В режиме перемещения стрелки меняют порядок, OK завершает, Назад отменяет. Избранное и общий список имеют независимый порядок, сохранённый между запусками.
- Удаление и настройки открываются штатными средствами Android. Удаление системных приложений ограничивает сам Android.

## Оформление и данные

Три тёмные темы, горизонтальные карточки с крупными иконками, анимация фокуса, отдельный ряд избранного. Размеры заданы в dp для ТВ, включая экран 1920×1080. Обои выбираются через системный проводник с сохранением доступа; если проводника нет, показано сообщение.

Часы используют время телевизора. В настройках введите город для погоды: Open-Meteo, HTTPS, без API-ключа и геолокации. Данные обновляются при открытии главной не чаще раза в 30 минут; время получения видно на экране. При ошибке показывается сохранённый результат с пометкой. Диагностика TCL показывает модель, Android, сборку, разрешение, память, свободное место и число приложений.

## Сборка и проверки

JDK 17, Android SDK 35, Gradle 8.9:

```sh
gradle testDebugUnitTest lintDebug assembleDebug
```

GitHub Actions запускается для push в main, pull request и вручную. Debug APK: `app/build/outputs/apk/debug/app-debug.apk`, артефакт `NovaTV-Launcher-v0.3-debug`.

Для установки поверх предыдущей версии нужны одинаковые applicationId **и сертификат подписи**. Debug-ключ в разных средах может различаться; используйте ключ предыдущей установки. Не удаляйте приложение ради обновления, если требуется сохранить данные.

## Проверка на телевизоре

Проверьте короткое/длительное OK и ENTER, отсутствие запуска после меню, все пункты меню, перестановку в обоих рядах и сохранение после перезапуска, отмену кнопкой Назад, установку/удаление приложений, темы, обои после перезапуска, погоду без сети и диагностику. Автотесты проверяют автомат короткого/длительного нажатия; аппаратные особенности пульта требуют проверки на TCL.

Приложение регистрирует HOME activity, но самостоятельно не меняет домашнее приложение, не отключает Google TV и не выполняет ADB/root-команд.
