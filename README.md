# NovaTV Launcher 0.6

Русскоязычный лаунчер для Android TV / Google TV 11–14 и TCL C835. `applicationId: ru.novatv.launcher`, версия 0.6.0, `versionCode: 7`. Системный HOME и Google TV самостоятельно не изменяет и не отключает.

## Интерфейс

Главный экран — строки ТВ-приложений, мобильных приложений, избранного и пользовательских категорий. Для ТВ используются баннеры из установленных пакетов; при их отсутствии — настоящая иконка приложения. Пустое избранное из скрытых приложений не создаёт пустой ряд. Обычный OK запускает приложение, удержание OK открывает меню без пункта «Открыть». Поддерживаются DPAD_CENTER, ENTER и NUMPAD_ENTER. Повторы клавиши не создают дополнительных запусков или меню. Потеря фокуса карточки/окна, удаление карточки и отменённое отпускание отменяют ожидающее нажатие.

Кнопка ☰ и кнопка MENU пульта открывают правую полупрозрачную панель. «Назад» возвращает на предыдущую страницу панели; на главном экране открывает меню. Слева остаётся живой предпросмотр с сохранением пропорций экрана. Все переключатели и ползунки сохраняются сразу, ползунки работают стрелками пульта. После закрытия панели возвращается фокус на приложение.

**Настройки NovaTV → Внешний вид:**

- Категории / строки: заголовки, значки, видимость встроенных разделов, интервал, поля, закрепление выбранной строки и прозрачность неактивных строк.
- Карточки: сетка от одной до трёх строк в категории (избранное остаётся горизонтальной строкой), ширина 80–240 dp, отдельные пропорции ТВ/мобильных карточек, скругление, интервалы, размеры иконок, TV-баннеры, названия и увеличение при фокусе.
- Обои: изображения и GIF через системный проводник, локальные видеообои без звука, затемнение, вписывание изображения и три темы фона. Видео и GIF приостанавливаются, когда NovaTV не виден. Доступ к файлу сохраняется через SAF. Возможность выбора файла зависит от наличия проводника, воспроизведение видео — от кодеков ТВ.
- Строка состояния: видимость, часы с форматом/размером/цветом/тенью, погода с размером/цветом/тенью, тип подключения, опциональный значок уведомлений.
- Шрифт: маленький / средний / большой, включая системные диалоги приложения. Акцент: пять цветов.

**Изменить категории:** создание, выбор приложений, видимость, переименование, порядок и удаление. У каждой категории независимый порядок карточек; скрытие не удаляет приложение из избранного. Перестановка карточек: стрелки, OK — сохранить, Назад — отменить.

**Все приложения:** боковой список с настоящими баннерами/иконками и меню по удержанию OK. Скрытые приложения доступны отдельно в «Основные»; восстановление через меню «Показать приложение» сохраняет избранное.

## Каналы и системные функции

«Изменить каналы» читает Preview Channels и Watch Next из системного TV Provider. Доступные рекомендации отображаются отдельными рядами с постерами и deep link в опубликовавшее приложение. Каналы можно скрывать, обновлять и включать/выключать целиком. Нет встроенного каталога фильмов: источник — приложения на вашем ТВ. Android может ограничить доступ к чужим каналам, а приложения могут не публиковать их вовсе; тогда показывается причина и пустые рекомендации не подменяются вымышленными карточками. Постеры загружаются по HTTPS или доступным content URI, ограничены по размеру и кешируются в памяти.

Источники сигнала берутся из `TvInputManager`; выбранный вход открывается штатным TV Intent. Доступность входов, заставки, настроек экрана, Bluetooth, голосового поиска и других экранов зависит от прошивки. Недоступный Intent показывает сообщение. Выключение телевизора, изменение системного лаунчера, перехват HOME и сетевой сервер дистанционного управления не добавлены.

Уведомления и «Сейчас играет» доступны после добровольного предоставления доступа Notification Listener в настройках Android. NovaTV не включает разрешение сам. Тексты уведомлений хранятся только в памяти, очищаются при отключении сервиса. Активные медиасессии открываются через предоставленные приложениями PendingIntent.

«Электропитание» позволяет оставить экран включённым только пока виден NovaTV и открыть штатные настройки экрана/заставки. «Основные → Автозапуск» запускает выбранное приложение один раз при новом старте Activity NovaTV, а не при возврате и не при загрузке Android.

## Родительский контроль и профили

PIN на 4–8 цифр защищает настройки и выбранные приложения **внутри NovaTV**. Хранится соль и PBKDF2-HMAC-SHA256, исходный PIN не сохраняется. После трёх неверных попыток — пауза 30 секунд в текущем процессе. PIN не блокирует Google TV, системные настройки, запуск из других приложений и сброс данных NovaTV; это локальное ограничение интерфейса, не системная защита. Если PIN забыт, потребуется очистка данных NovaTV с потерей его настроек.

Профили экрана сохраняют локальные параметры оформления и URI обоев. PIN и список защищённых приложений в профиль не включаются. Профили можно применить и удалить. Сброс оформления сохраняет избранное, категории и установленные приложения.

## Погода

Выберите город в «Внешний вид → Строка состояния → Погода», введите название, нажмите «Найти» и выберите регион. Погода: Open-Meteo current → совместимый current_weather → резерв wttr.in по координатам. HTTPS, тайм-ауты, кеш 30 минут, ручной повтор, защита от ответа для старого города. Источник и время получения указаны рядом с результатом. При ошибке остаются прежние данные с пометкой; конкретная ошибка HTTP/DNS/TLS/тайм-аута доступна в настройках погоды. Доступность сервисов из сети TCL и причина ранее наблюдавшегося сбоя требуют проверки на самом ТВ.

## Сборка и проверки

JDK 17, Android SDK 35, Gradle 8.9:

```sh
gradle testDebugUnitTest lintDebug assembleDebug
```

GitHub Actions выполняет тесты, Lint и сборку для PR, push в main и ручного запуска. APK: `app/build/outputs/apk/debug/app-debug.apk`, артефакт `NovaTV-Launcher-debug`. Отчёты, результаты тестов и изображения Android View: артефакт `NovaTV-checks`.

Автотесты проверяют автомат OK, сохранения порядка и скрытых приложений, сетевых ошибок и запросов погоды, геометрии карточек и PIN. Robolectric с native graphics проверяет настоящую Activity при 1920×1080: фильтрацию избранного, открытие/возврат панели, изменение ползунка стрелкой и сохранение фокуса. Изображения в `app/build/reports/ui/` получены из Android View с контролируемыми тестовыми приложениями; это не фотографии TCL и не доказательство работы кодеков, TV Provider или сетевых сервисов на физическом ТВ.

Для установки поверх предыдущей версии нужны одинаковые applicationId **и сертификат подписи**. Debug-ключи локальной среды и GitHub Actions могут различаться. Используйте ключ прежней установки, если нужно сохранить данные.

## Проверить на TCL C835

Короткое и длительное OK/ENTER без двойного запуска; вложенные меню и Назад; длительный скролл ползунков; сохранение настроек и фокуса после перезапуска; отдельный порядок категорий; скрыть последнее избранное и восстановить; баннеры приложений; GIF/видеообои и уход/возврат; доступ/отказ TV Provider; включение и отзыв доступа к уведомлениям; PIN и пауза после ошибок; профили и отмена выбора файла; погода из сети телевизора и её диагностика.

Не реализованы все возможности Projectivy один в один: пакеты значков, Lottie/RTSP-фоны, перехват HOME, системное выключение и собственный сетевой пульт не добавлены. Для них нет неработающих переключателей. Новая структура меню и оформление реализованы собственными Android View.
