# NovaTV Launcher 0.2

Тестовая версия для Android TV 11–14, в том числе TCL C835. Полностью русскоязычный интерфейс, навигация D-pad, верхнее меню, крупный декоративный баннер, горизонтальные ряды настоящих приложений с иконками, избранное и ручная перестановка избранного, темы, часы, диагностика. Погода не показывается без данных: подключение погодного сервиса запланировано.

## Сборка
JDK 17 + Android SDK 35 + Gradle 8.9: `gradle assembleDebug`. На GitHub: Actions → Сборка APK → Artifacts → NovaTV-Launcher-v0.2-debug.

## Установка
Установите APK как обычное Android-приложение на ТВ. Не отключайте системный Google TV Launcher. Назначение HOME по умолчанию пока не требуется.

## Ограничения
Это самостоятельный интерфейс, а не копия Google TV. Баннер декоративный и не использует защищённые постеры. Нет внешних рекомендаций, онлайн-погоды и загрузки пользовательских обоев. Системные приложения могут не публиковать LAUNCHER/LEANBACK_LAUNCHER activity.
